# 目标图像侦察报告（绿色发光目标）

本文件是开发前对两个输入视频做的快速分析，供检测/PnP/验证各工作流参考。
原始统计脚本与调试图保存在 `data/recon/`。

## 1. 输入视频

| 文件 | 分辨率 | 帧率 | 帧数 | 时长 | 备注 |
| --- | --- | --- | --- | --- | --- |
| `data/videos/v1_green_target.mp4` | 720x1280（竖屏） | 29.94 fps | 539 | 18.0 s | 相机基本静止，目标小幅转动/缩放 |
| `data/videos/v2_green_target.mp4` | 720x1280（竖屏） | 30.00 fps | 406 | 13.5 s | 相机快速绕目标移动，目标在画面中大幅移动、有运动模糊 |

两段视频是同一目标（白色 3D 打印"V 形"支架上的绿色发光灯）的手机拍摄，
并非 OpenMV 相机原始图像；720x1280 下相机内参按 26mm 等效焦距估计：

```text
fx = fy = 960 px, cx = 360, cy = 640, dist = 0
```

（真实部署相机为 OpenMV H7 Plus + 2.8mm 镜头，见 `config/openmv_h7plus_qvga.yaml`。）

## 2. 目标外观与可用几何特征

目标由三部分组成（见 `data/recon/v1_target_zoom.png`）：

1. **中央白色圆盘**：过曝的亮白圆形区域，直径在画面中约 50–125 px（最近/最远）。
2. **绿色发光圆环**：紧贴白盘外侧的一圈深绿色环，其内边界 == 白盘边界（干净、闭合、近似椭圆）。
3. **绿色发光扩散片**：V 形/蝶形的半透明绿色发光片，向白盘两侧展开；
   由于发光扩散，绿色区域边界模糊、且与环境中的绿色物体混叠。

**几何结论**：白色圆盘（= 绿色圆环内边界）是唯一干净、闭合、可稳定拟合椭圆的圆特征，
作为 PnP 的已知半径圆（`target.disc_diameter_mm`，默认 50 mm，需现场卡尺复核）。
绿色发光区域用于**检测定位与颜色校验**（必须在白盘周围检测到绿色环/扩散片）。

`disc_diameter_mm` 只影响距离输出：圆特征位姿解算对目标模型整体缩放不敏感，
yaw/pitch 理论上严格不随该尺寸变化。

## 3. 检测相关统计（宽阈值绿色掩膜）

宽阈值：HSV `H∈[35,100], S≥60, V≥40`，开闭运算后最大绿色连通域统计
（完整逐帧数据见 `data/recon/v1_green_detect.csv` / `v2_green_detect.csv`）：

- 绿色像素质心 HSV 均值：H≈56、S≈135–150、V≈150–160（OpenCV H 范围 0–180）。
- 绿色目标在整幅画面中经常不是最大绿色连通域：实验室背景存在绿色椅子/货架/反光，
  因此 **全图直接取最大绿色 blob 会误检**，必须结合"白盘 + 绿色环"结构校验，
  并在跟踪时使用 ROI 预测。
- 白盘检测（高亮低饱和掩膜 `V≥225, S≤45`）非常干净：
  例如 v1 第 0 帧白盘 `bbox=(534,652,90,96)`、椭圆半轴 `(44.6,48.6)`；
  v1 第 300 帧 `bbox=(300,588,102,105)`；v2 第 0 帧 `bbox=(306,408,86,72)`。
- 白盘椭圆长/短轴比一般在 0.85–1.0（目标基本正对相机，小角度倾斜）；
  快速运动帧会有轻微运动模糊（椭圆拟合仍可用，但边缘变软）。

## 5. 对算法的直接启示

1. **检测**：绿色掩膜只用于候选定位/颜色验证；几何拟合对象是白盘边界椭圆。
   优先使用"绿色连通域中的孔洞（白盘）"直接得到闭合轮廓，再叠加白盘亮度/饱和度校验；
   绿色环断裂时退化为"高亮白盘 + 周围绿色环校验"。
2. **候选筛选**：必须包含绿色环/扩散片的绿色像素比例校验（排除背景绿色物体、白色灯具）。
3. **跟踪**：v2 运动快，单帧中心位移可达 ~50 px，必须做 ROI 预测 + 全图重捕；
   目标短时被自身 V 形支架遮挡/出画时依赖 Kalman 外推。
4. **PnP**：目标基本正对相机（倾角小），圆特征 PnP 在正对时二义性弱，
   但仍需按 facing + 时序连续性消除镜像解。
5. **验证**：真实视频无真值，用"PnP 视线角 vs 白盘椭圆中心视线角偏差"、
   PnP 重投影误差、滤波平滑度/连续性做量化验证；绝对精度用合成数据闭环验证。
